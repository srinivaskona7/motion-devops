# Universal Tech Researcher & Architecture Specialist

This skill governs deep technical research and pedagogical decomposition across **ANY software, hardware, or cloud technology**.

## Universal Domain Coverage Matrix

1. **AI / ML & LLMs**: Transformer architecture, Attention mechanisms, RAG pipelines, Vector databases, vLLM / TensorRT-LLM inference, LoRA fine-tuning, Quantization (GGUF/AWQ).
2. **Backend & Distributed Systems**: Event-driven architectures, Kafka partitions, Raft consensus, gRPC streaming, GraphQL vs REST, Redis caching patterns, Saga transactions.
3. **Frontend & Mobile**: React Server Components, Next.js App Router, Flutter/React Native bridges, WebAssembly (Wasm), Canvas/WebGL rendering, CSS rendering engines.
4. **Databases & Storage**: LSM-Trees vs B-Trees, PostgreSQL MVCC, Cassandra wide-column partitioning, CockroachDB distributed SQL, ClickHouse columnar analytics.
5. **Security & Cryptography**: Zero-Knowledge Proofs (ZKP), OAuth2/OIDC flows, JWT replay attacks, mTLS handshakes, eBPF network security, Linux namespaces.
6. **Cloud & Infrastructure**: Kubernetes, Istio Service Mesh, Linux kernel primitives (cgroups, epoll), Terraform IaC, AWS/GCP serverless.

## Universal 5-Layer Pedagogical Decomposition

For every concept, author `contents/<slug>.md` covering:
1. **The Core Dilemma / "Why"**: The breaking point or bottleneck that forced the creation of this technology.
2. **The Architectural Hierarchy ("What")**: The roles, components, and data structures involved.
3. **Live Packet / Byte / State Lifecycle ("How")**: Step-by-step tracing of data moving through the system.
4. **Crisis & Debugging Simulation**: The exact failure mode (outage, crash, latency spike) and live CLI/code fix.
5. **Universal Production Cheat-Sheet**: Architectural trade-offs, when NOT to use it, and golden metrics.
